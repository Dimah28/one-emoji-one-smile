# One Emoji, One Smile

Entry for the make.fun bounty
[u-0xkianno-one-emoji-one-smile-5470751f](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f).

`main.py` (Python 3.13, standard library only) writes exactly one emoji —
the hugging face 🤗 — to `/output/entry.txt`: open arms and a warm smile
offered to a stranger. Warm at first glance, universal, a deliberate pick
rather than the default smiley, and right coming from someone unknown.
